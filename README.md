# StyleMate AI

给自己用的智能衣橱。今天穿什么、衣柜里有什么、按天气搭配、把穿过的日子记在日历上，买新衣服之前先问一声衣橱。

界面是简体中文，时间用北京时间（`Asia/Shanghai`），价格是人民币，购买搜索打开淘宝和京东。

## 本地运行

需要 Node.js 22。

```bash
npm install
npm run dev
```

浏览器打开 [http://127.0.0.1:43123](http://127.0.0.1:43123)。

```bash
npm run typecheck
npm test
npm run build
```

没设置 `DATABASE_URL` 时，账号和衣橱写在项目里的 `.data/pglite`（嵌入式 Postgres）。这个目录不要提交。线上用 Render 和 Neon，步骤见 [DEPLOY.md](DEPLOY.md)。

## 环境变量

复制下面的名字到本机环境即可，没有密钥也能打开应用。

| 变量 | 作用 |
| --- | --- |
| `XAI_API_KEY` | xAI 的密钥。衣物照片识别、造型建议、「买前问衣橱」都用它。不填时：识别改为手填；搭配和买前建议改用衣橱里的规则，不再编造匹配百分比。 |
| `BETTER_AUTH_SECRET` | 登录会话的签名密钥。正式部署请设置一长串随机字符。本地不填会在进程里临时生成，重启后旧登录会失效。 |
| `BETTER_AUTH_URL` | 网站对外的地址，例如 `https://style.example.com`。本地开发不用填。 |
| `DATABASE_URL` | Postgres 连接串。不填就用上面的本地 PGLite。 |
| `VITE_SOCIAL_LOGIN` | 设为 `true` 才在登录页显示 Google / X。 |
| `GROK_AUTH_CLIENT_ID` | 和上面一起用的 OAuth 客户端 id。两个都要有，第三方登录才会真正启用。 |
| `GROK_AUTH_CLIENT_SECRET` | 对应的客户端密钥。 |
| `GROK_AUTH_ISSUER` | 可选。OAuth 服务地址，默认 `https://auth.grok.me`。 |

不要把密钥写进仓库。

## 这次产品上的变化

1. 补上了压缩包里缺的页面和模块：今日穿搭、衣柜、我的、天气、登录注册，以及构建要用的认证服务端。天气优先用 Open-Meteo（不用密钥），失败再试别的预报，最后按「凉爽」继续搭配。
2. 面向中国大陆：简体文案、上海时区、人民币、淘宝 / 京东搜索、系统中文字体（不再加载 Google Fonts）。默认只有邮箱和密码登录。
3. 登录后的衣物、造型、日历和照片存在服务器数据库里，不再只靠浏览器 localStorage。这个账号第一次登录时，如果服务器还是空的，会把这台设备上的旧衣橱导入一次。
4. 造型建议走 xAI。只使用衣橱里真实存在的单品，每套附一句中文说明。没有密钥时退回规则搭配。页面上不再显示随机的「匹配度」。
5. 新功能「买前问衣橱」：上传照片，或贴商品链接 / 描述。应用会说它大概能和现有衣服配出几套、是不是已经有类似的，以及建议买还是先不买。

未登录时仍可以在这台设备上试用示例衣橱，数据留在本地。登录之后以服务器为准。
